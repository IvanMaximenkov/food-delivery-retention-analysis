# Продуктовый анализ retention и churn в сервисе доставки еды

End-to-end аналитический проект по продуктовой аналитике и прогнозированию оттока пользователей в food delivery-сервисе.

## О проекте

Проект моделирует задачу продуктового аналитика / junior data scientist в сервисе доставки еды. Основная цель — понять, какие факторы влияют на удержание пользователей, как сегментировать клиентскую базу и какие продуктовые решения могут снизить churn.

## Бизнес-задача

Для food delivery-сервисов рост без удержания быстро становится дорогим: стоимость привлечения пользователей растет, а значительная часть клиентов делает 1–2 заказа и перестает пользоваться сервисом.

Цель проекта:
- проанализировать раннее поведение пользователей;
- оценить retention через повторные заказы;
- сегментировать клиентскую базу;
- подготовить основу для churn prediction;
- сформулировать продуктовые гипотезы и бизнес-рекомендации.

## Что входит в проект

- генерация синтетических, но реалистичных данных food delivery-продукта;
- SQL-схема и загрузка данных в реляционную БД;
- exploratory data analysis;
- когортный retention-анализ;
- RFM-сегментация пользователей;
- A/B-анализ продуктового эксперимента;
- ML-пайплайн для прогнозирования churn;
- визуализации и итоговая аналитическая интерпретация.
